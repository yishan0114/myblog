在[〈這個暑假我都在做什麼？〉](https://www.yishantsai.com/post/summer-vacation/)這篇文中有提到我 6/22-6/26 參加旅行社的行程去北海道玩，紀錄一下旅遊過程！

### 第一天

這次搭乘的是中華航空，抵達札幌啦。
{{< figure src="/images/20260622_121815.jpg" width="70%" >}}
支笏（ㄏㄨˋ）湖。
{{< figure src="/images/20260622_153453.jpg" width="70%" >}}
第一支霜淇淋。之後的每一天幾乎都有吃霜淇淋，來北海道就是要吃牛奶口味啊！
{{< figure src="/images/20260622_154226.jpg" width="70%" >}}
也買了干貝，超級大顆。來北海道除了冰淇淋還要吃海鮮啊！這個攤販就在支笏湖旁邊，很值得買。
{{< figure src="/images/20260622_154304.jpg" width="70%" >}}
當天晚餐在飯店吃，雖然看起來份量少少的，但我吃完意外的很飽。
{{< figure src="/images/20260622_173208.jpg" width="70%" >}}
我在飯店附近找到一間唐吉訶德，所以我和家人吃完晚餐去逛了一下。不過這間唐吉訶德很特別，不像其他間東西、走道都很壅擠，整體來說很明亮、寬敞，但是品項反而沒有很齊全。在那邊買了促銷的梅酒（價格忘記了），很便宜但是很甜很好喝。
{{< figure src="/images/20260622_200738.jpg" width="70%" >}}

### 第二天

大沼國定公園。那天天色陰陰的有點可惜，天氣好的話看起來會更漂亮。
{{< figure src="/images/20260623_124240.jpg" width="70%" >}}
午餐是火鍋，圖中是三人份。
{{< figure src="/images/20260623_130230.jpg" width="70%" >}}
函館女子修道院。整個園區其實蠻小的，很快就可以逛完。
{{< figure src="/images/20260623_145439.jpg" width="70%" >}}
修道院的附近有一間店，在那邊買了牛奶口味的霜淇淋。這支號稱是北海道第一名的冰淇淋，果然是這次旅程中我覺得牛奶味最香的，這個口味也是店內的熱銷第一名。
{{< figure src="/images/20260623_150726.jpg" width="70%" >}}
因為「期間限定」而買的麝香葡萄口味霜淇淋，吃完的感想：還是直接吃麝香葡萄，並相信熱銷第一名就好⋯⋯。
{{< figure src="/images/20260623_151134.jpg" width="70%" >}}
前面在修道院時雨下得頗大，在前往金森倉庫的途中天氣放晴，因此很幸運可以看到彩虹！
{{< figure src="/images/20260623_153923(0).jpg" width="70%" >}}
金森倉庫很有名的起司蛋糕和咖啡。上面插著的紙片可以拿來當小湯匙用，很有創意的設計。起司蛋糕很綿密，好吃！
{{< figure src="/images/20260623_160027.jpg" width="70%" >}}
這邊有點類似台北的華山或松菸，倉庫內賣很多伴手禮和小物，不過當時礙於行程沒有太多時間可以逛，有點可惜。
{{< figure src="/images/20260623_162729.jpg" width="70%" >}}
大約晚上 7 點多抵達函館山，可惜當時不僅太陽還沒下山，霧還有點大，不過也因為這樣人沒有很多。由於巴士司機有工作時長的限制，所以我們只能待到 7 點半就要搭纜車下山，雖然後來天色有變暗一點，不過霧也越來越大，一開始到的時候已經是最清楚的景色了。
{{< figure src="/images/20260623_191307.jpg" width="70%" >}}

### 第三天

函館朝市賣的哈密瓜，超級甜，而且現場都切好了還有附竹籤，買了可以直接吃掉。除了蔬果之外，那邊也賣很多海鮮，但是地板很乾淨，不會濕濕的，逛起來很舒服。（之前常常去基隆崁仔頂，地板都濕濕的）
{{< figure src="/images/20260624_090400.jpg" width="70%" >}}
逛函館朝市的時候經過一間賣起司干貝、起司魷魚的店，原本我們沒有要買的，但是老闆太熱情，一直不斷讓我們試吃，很難拒絕也很難直接離開。最後我媽購入大包的起司干貝，老闆還送我們小包的。（其實讓客人一直試吃就是他的推銷手法吧）
{{< figure src="/images/20260624_091938 (1).jpg" width="70%" >}}
途中經過的森林，看起來超大片的，因為很少見所以拍下來了。
{{< figure src="/images/20260624_103615.jpg" width="70%" >}}
洞爺湖旁邊的伴手禮店賣的布丁和優格，布丁外面有一層膜，要先戳破才能吃，外型和吃法都很酷，優酪乳則是喝起來很濃郁。
{{< figure src="/images/20260624_122331.jpg" width="70%" >}}
洞爺湖。
{{< figure src="/images/20260624_125113.jpg" width="70%" >}}
第三天的午餐是這幾天下來最普通的一餐，雖然導遊說這是很特別的「釜飯」，但其實我和家人吃起來都覺得像是普通的白飯。吃午餐的地方在朝和新山的附近，因此吃完之後就去那邊晃了一下，不過忘記拍照了。
{{< figure src="/images/20260624_131847.jpg" width="70%" >}}
登別地獄谷。那邊有很多步道可以走，認真逛的話應該可以待很久。
{{< figure src="/images/20260624_151530.jpg" width="70%" >}}
大通公園和札幌電視塔。
{{< figure src="/images/20260624_174322(0).jpg" width="70%" >}}
晚餐是吃到飽，有螃蟹、干貝、肉片、壽司等等，酒也喝到飽。
{{< figure src="/images/20260624_191509.jpg" width="70%" >}}

### 第四天

很喜歡小樽運河商店街的西式建築。
{{< figure src="/images/20260625_114922.jpg" width="70%" >}}
午餐吃壽司和小火鍋。
{{< figure src="/images/20260625_115536.jpg" width="70%" >}}
有名的北菓樓泡芙，內餡有濃濃的奶味。
{{< figure src="/images/20260625_124824.jpg" width="70%" >}}
小樽運河的河畔走起來很舒服，還可以看到有人在划船，很浪漫也很愜意。
{{< figure src="/images/20260625_132440.jpg" width="70%" >}}
這天晚餐自理，於是我們去薄野車站買了鰻魚飯便當。
{{< figure src="/images/20260625_195354.jpg" width="70%" >}}
在博野車站又看到霜淇淋，肯定要吃吃看。再次決定下次去北海道只吃純牛奶口味的霜淇淋，綜合口味反而會讓巧克力蓋過牛奶的味道，因而變得沒有特色了。
{{< figure src="/images/20260625_180804.jpg" width="70%" >}}
買完晚餐後我們經過一間百貨公司，由於這次旅行時我媽發現原本的墨鏡壞了，正好在百貨公司看到好看的墨鏡。原本我媽還在猶豫要不要買，我在旁邊說：「買啦！中意的伴手禮有印北海道限定的話都一定要買了，這個墨鏡也是北海道限定啊！」於是我媽就被我說服了。
{{< figure src="/images/20260625_202755.jpg" width="70%" >}}

### 第五天

最後一天的行程只有 Outlet，不過逛了一圈後沒有特別想買的東西，於是又跑去吃冰啦！原本以為只是普通的抹茶冰淇淋，沒想到中間有一層是甜甜圈，完全被驚艷到了，而且很搭。
{{< figure src="/images/20260626_105549.jpg" width="70%" >}}
回程的飛機餐，和去程一樣是搭華航。目前吃過的華航飛機餐印象中都不錯吃。
{{< figure src="/images/20260626_163204.jpg" width="70%" >}}

這次來北海道每天都在吃海鮮，不是干貝就是生魚片、熟鮭魚、壽司。這幾天的心路歷程大概是「海鮮！！海鮮！海鮮。海鮮⋯⋯。」一開始很幸福，到後面越來越膩，並決定回台灣之後一個月不吃海鮮，不過這也是奢侈又難得的煩惱呢！

之後也想體驗看看冬季的北海島，雖然很冷，但相同的道路、建築和湖被白雪覆蓋一定會是完全不同的景色。
